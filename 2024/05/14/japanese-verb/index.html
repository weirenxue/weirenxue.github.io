[日語] 動詞活用規則與重音規則

發表於 2024-05-14 更新於 2024-05-21 分類於 日語筆記 閱讀次數：
這裡記錄了 N5 與 N4 會遇到的動詞變化規則與重音規則。

前言

這裡記錄了 N5 與 N4 會遇到的動詞變化規則與重音規則。

動詞活用

  • 活用的意思為有變化，動詞活用即動詞變化，變化的最終目的只是為了好唸，不需要糾結於為什麼這樣變化。
  • 日語動詞最大的特徵就是最後一個字都在 う 段音 (うくすつぬふむゆる)。
  • 日語的動詞分為「語幹」及「語尾」，無論動詞本身有幾個字，動詞的「最後一個字」就叫做「語尾、字尾」，其他在語尾前不管有幾個字都稱為「語幹」，且只有「語尾」會變化。
    • 買 (か) う 的語幹為「買 (か) 」，語尾為「う」。
    • 食 (た) べる 的語幹為「食 (た) べ」，語尾為「る」。

三種動詞

日語的動詞依變化規則不同可以分為 3 種，即「五段動詞、I 類」、「上下段動詞、II 類」與「變格活用動詞、III 類」。

  • 五段動詞
    • 語尾不是 る 的動詞一定為五段動詞。
    • 不為上下段動詞或變格活用動詞則為五段動詞。
  • 上下段動詞
    • 動詞的語尾一定是 る 且語尾 る 的前面那個字必須是 い 段音 (いきしちにひみり) 或是 え 段音 (えけせてねへめれ)。
      • 若滿足語尾 る 的前面那個字是 い 段音則稱為上段動詞 (う 段的上一段)。
      • 若滿足語尾 る 的前面那個字是 え 段音則稱為下段動詞 (う 段的下一段)。
    • 例外：要 (い) る、知 (し) る、入 (はい) る、帰 (かえ) る、切 (き) る 等等，這些動詞雖然語尾 る 前皆為 い 段音或 え 段音，但這些音是包含在漢字內的，於是被歸類在五段動詞。
  • 變格活用動詞
    • 變格活用的意思為不規則變化，幸好這一類只有兩個動詞，直接記住變化結果即可。
    • カ 行變格活用動詞「来 (く) る」。
    • サ 行變格活用動詞「する」。

未然形(ない形)＋ない

ない 形本身是不包含 ない 的，指的是後面接著 ない 的字，例如：買 (か) う 的否定為 買 (か) わない，把 ない 去掉後剩下的字 買 (か) わ 才是 買 (か) う 的 ない 形。

  • 五段動詞
    • 變化規則：動詞去掉語尾 (う段音) 加上 あ 段音＋ない。
    • 重音規則：若原型動詞的重音為 0，則變化後重音在 0；若不是 0，則重音在 あ 段音。
    • 範例：
      • 0買 (か) う → 0買 (か) わない

        う 對應的 あ 段音原本為 あ，但為了好唸，會用 わ 來取代。

      • 1書 (か) く → 2書 (か) かない
      • 1脱 (ぬ) ぐ → 2脱 (ぬ) がない
      • 0なくす → 0なくさない
      • 1待 (ま) つ → 2待 (ま) たない
      • 0死 (し) ぬ → 0死 (し) なない
      • 0呼 (よ) ぶ → 0呼 (よ) ばない
      • 1飲 (の) む → 2飲 (の) まない
      • 1帰 (かえ) る → 3帰 (かえ) らない
  • 上下段動詞
    • 變化規則：動詞去掉語尾 (る) 直接＋ない。
    • 重音規則：若原型動詞的重音為 0，則變化後重音在 0；若不是 0，則重音在 な 前一個字。
    • 範例：
      • 0借 (か) りる → 0借 (か) りない
      • 2食 (た) べる → 2食 (た) べない
  • 變格活用動詞
    • 1来 (く) る → 1来 (こ) ない
    • 0する → 0しない

連用形(ます形)＋ます

ます 形本身是不包含 ます 的，指的是後面接著 ます 的字，例如：把 買 (か) います 的 ます 去掉後剩下的 買 (か) い 才是 買 (か) う 的 ます 形。

  • 五段動詞
    • 變化規則：動詞去掉語尾 (う段音) 加上 い 段音＋ます。
    • 重音規則：重音在 ま。
    • 範例：
      • 0買 (か) う → 3買 (か) います
      • 1書 (か) く → 3書 (か) きます
      • 1脱 (ぬ) ぐ → 3脱 (ぬ) ぎます
      • 0なくす → 4なくします
      • 1待 (ま) つ → 3待 (ま) ちます
      • 0死 (し) ぬ → 3死 (し) にます
      • 0呼 (よ) ぶ → 3呼 (よ) びます
      • 1飲 (の) む → 3飲 (の) みます
      • 1帰 (かえ) る → 4帰 (かえ) ります
  • 上下段動詞
    • 變化規則：動詞去掉語尾 (る) 直接＋ます。
    • 重音規則：重音在 ま。
    • 範例：
      • 0借 (か) りる → 3借 (か) ります
      • 2食 (た) べる → 3食 (た) べます
  • 變格活用動詞
    • 1来 (く) る → 2来 (き) ます
    • 0する → 2します

中止形(て形)、完了形(た形)

て 形與 た 形的變化方式一樣，差別只在於一個結尾為 て 一個為 た。

  • 五段動詞

    • 重音規則：若原型動詞的重音為 0，則變化後重音在 0；若是 1，變化後的重音還是 1；若不是 0 或 1，則重音在 て/た 前兩個字。
    • 變化規則 1：若 ます 形的最後一個音是 い、ち、り，全部改為促音 っ 再加上 て/た。
      範例：
      • 0買 (か) う → 3買 (か) います → 0買 (か) って/た
      • 1待 (ま) つ → 3待 (ま) ちます → 1待 (ま) って/た
      • 1帰 (かえ) る → 4帰 (かえ) ります → 1帰 (かえ) って/た
    • 變化規則 2：若 ます 形的最後一個音是 に、み、び，全部改為 ん 再加上 で/だ。
      範例：
      • 0死 (し) ぬ → 3死 (し) にます → 0死 (し) んで/だ
      • 1飲 (の) む → 3飲 (の) みます → 1飲 (の) んで/だ
      • 0呼 (よ) ぶ → 3呼 (よ) びます → 0呼 (よ) んで/だ
    • 變化規則 3：若 ます 形的最後一個音是 き，改為 い 再加上 て/た。
      範例：
      • 1書 (か) く → 3書 (か) きます → 1書 (か) いて/た
    • 變化規則 4：若 ます 形的最後一個音是 ぎ，改為 い 再加上 で/だ。
      範例：
      • 1脱 (ぬ) ぐ → 3脱 (ぬ) ぎます → 1脱 (ぬ) いで/だ
    • 變化規則 5：若 ます 形的最後一個音是 し，直接加 て/た。
      範例：
      • 0なくす → 0なくして/た

    唯一的例外：原本「行 (い) きます」套用變化規則 3 會變成「行 (い) いて/た」，但兩個 い 放在一起不好唸，所以改為促音「0行 (い) って/た」。

  • 上下段動詞
    • 變化規則：動詞去掉語尾 (る) 直接＋て/た。
    • 重音規則：若原型動詞的重音為 0，則變化後重音在 0；若是 1，變化後的重音還是 1；若不是 0 或 1，則重音在 て/た 前兩個字。
    • 範例：
      • 0借 (か) りる → 0借 (か) りて/た
      • 2食 (た) べる → 1食 (た) べて/た
  • 變格活用動詞
    • 1来 (く) る → 1来 (き) て/た
    • 0する → 0して/た

条件形(假定形 ~ば)

假定形以 ば 結尾，ば 又稱為假定助動詞。

  • 五段動詞
    • 變化規則：動詞去掉語尾 (う段音) 加上 え 段音＋ば。
    • 重音規則：若原型動詞的重音為 0，則變化後重音在 ば 前一個字；若不是 0，則重音在 ば 前兩個字。
    • 範例：
      • 0買 (か) う → 2買 (か) えば
      • 1書 (か) く → 1書 (か) けば
      • 1脱 (ぬ) ぐ → 1脱 (ぬ) げば
      • 0なくす → 3なくせば
      • 1待 (ま) つ → 1待 (ま) てば
      • 0死 (し) ぬ → 2死 (し) ねば
      • 0呼 (よ) ぶ → 2呼 (よ) べば
      • 1飲 (の) む → 1飲 (の) めば
      • 1帰 (かえ) る → 2帰 (かえ) れば
  • 上下段動詞
    • 變化規則：動詞去掉語尾 (る) 直接＋れ＋ば。
    • 重音規則：若原型動詞的重音為 0，則變化後重音在 ば 前一個字；若不是 0，則重音在 ば 前兩個字。
    • 範例：
      • 0借 (か) りる → 3借 (か) りれば
      • 2食 (た) べる → 2食 (た) べれば
  • 變格活用動詞
    • 1来 (く) る → 1来 (く) れば
    • 0する → 2すれば

命令形

  • 五段動詞
    • 變化規則：動詞去掉語尾 (う段音) 加上 え 段音。
    • 重音規則：重音不變。
    • 範例：
      • 0買 (か) う → 0買 (か) え
      • 1書 (か) く → 1書 (か) け
      • 1脱 (ぬ) ぐ → 1脱 (ぬ) げ
      • 0なくす → 0なくせ
      • 1待 (ま) つ → 1待 (ま) て
      • 0死 (し) ぬ → 0死 (し) ね
      • 0呼 (よ) ぶ → 0呼 (よ) べ
      • 1飲 (の) む → 1飲 (の) め
      • 1帰 (かえ) る → 1帰 (かえ) れ
  • 上下段動詞
    • 變化規則：動詞去掉語尾 (る) 直接＋ろ 或 よ 兩者皆可，ろ 較常見到。
    • 重音規則：重音不變。
    • 範例：
      • 0借 (か) りる → 0借 (か) りろ/よ
      • 2食 (た) べる → 2食 (た) べろ/よ
  • 變格活用動詞
    • 1来 (く) る → 1来 (こ) い
    • 0する → 0しろ 或 1せよ

禁止形

表示強烈禁止。

  • 五段動詞
    • 變化規則：原型動詞直接＋な。
    • 重音規則：若原型動詞的重音為 0，則變化後重音在 な 前一個字；若不是 0，則重音不變。
    • 範例：
      • 0買 (か) う → 2買 (か) うな
      • 1書 (か) く → 1書 (か) くな
      • 1脱 (ぬ) ぐ → 1脱 (ぬ) ぐな
      • 0なくす → 3なくすな
      • 1待 (ま) つ → 1待 (ま) つな
      • 0死 (し) ぬ → 2死 (し) ぬな
      • 0呼 (よ) ぶ → 2呼 (よ) ぶな
      • 1飲 (の) む → 1飲 (の) むな
      • 1帰 (かえ) る → 1帰 (かえ) るな
  • 上下段動詞
    • 變化規則：原型動詞直接＋な。
    • 重音規則：若原型動詞的重音為 0，則變化後重音在 な 前一個字；若不是 0，則重音不變。
    • 範例：
      • 0借 (か) りる → 3借 (か) りるな
      • 2食 (た) べる → 2食 (た) べるな
  • 變格活用動詞
    • 1来 (く) る → 1来 (く) るな
    • 0する → 2するな

意向形(意量形 ~う)

意量形以 う 結尾，う 又稱為意量助動詞。

  • 五段動詞
    • 變化規則：動詞去掉語尾 (う段音) 加上 お 段音＋う。
    • 重音規則：重音在 お 段音。
    • 範例：
      • 0買 (か) う → 2買 (か) おう
      • 1書 (か) く → 2書 (か) こう
      • 1脱 (ぬ) ぐ → 2脱 (ぬ) ごう
      • 0なくす → 3なくそう
      • 1待 (ま) つ → 2待 (ま) とう
      • 0死 (し) ぬ → 2死 (し) のう
      • 0呼 (よ) ぶ → 2呼 (よ) ぼう
      • 1飲 (の) む → 2飲 (の) もう
      • 1帰 (かえ) る → 3帰 (かえ) ろう
  • 上下段動詞
    • 變化規則：動詞去掉語尾 (る) 直接＋よ＋う。
    • 重音規則：重音在 よ。
    • 範例：
      • 0借 (か) りる → 3借 (か) りよう
      • 2食 (た) べる → 3食 (た) べよう
  • 變格活用動詞
    • 1来 (く) る → 2来 (こ) よう
    • 0する → 2しよう

可能形

將動詞變化成另外一個動詞，所有變化後的動詞皆為上下段動詞，並且在原本的意思加上「可以、能夠、會」。例如：買 (か) う 的可能形為 買 (か) える，意思由原本的「買」變成「可以買、能夠買、會買」。

  • 五段動詞
    • 變化規則：動詞去掉語尾 (う段音) 加上 え 段音＋る。
    • 重音規則：若原型動詞的重音為 0，則變化後重音在 0；若不是 0，則重音在 え 段音。
    • 範例：
      • 0買 (か) う → 0買 (か) える
      • 1書 (か) く → 2書 (か) ける
      • 1脱 (ぬ) ぐ → 2脱 (ぬ) げる
      • 0なくす → 0なくせる
      • 1待 (ま) つ → 2待 (ま) てる
      • 0死 (し) ぬ → 0死 (し) ねる
      • 0呼 (よ) ぶ → 0呼 (よ) べる
      • 1飲 (の) む → 2飲 (の) める
      • 1帰 (かえ) る → 3帰 (かえ) れる
  • 上下段動詞
    • 變化規則：動詞去掉語尾 (る) 直接＋られ＋る。
    • 重音規則：若原型動詞的重音為 0，則變化後重音在 0；若不是 0，則重音在 れ。
    • 範例：
      • 0借 (か) りる → 0借 (か) りられる
      • 2食 (た) べる → 4食 (た) べられる
  • 變格活用動詞
    • 1来 (く) る → 3来 (こ) られる
    • 0する → 2できる

受身形(被動)

將動詞變化成另外一個動詞，所有變化後的動詞皆為上下段動詞，並且在原本的意思加上「被」。例如：買 (か) う 的受身形為 買 (か) われる，意思由原本的「買」變成「被買」。

  • 五段動詞
    • 變化規則：ない 形＋れる。
    • 重音規則：若原型動詞的重音為 0，則變化後重音在 0；若不是 0，則重音在 れ。
    • 範例：
      • 0買 (か) う → 0買 (か) われる
      • 1書 (か) く → 3書 (か) かれる
      • 1脱 (ぬ) ぐ → 3脱 (ぬ) がれる
      • 0なくす → 0なくされる
      • 1待 (ま) つ → 3待 (ま) たれる
      • 0死 (し) ぬ → 0死 (し) なれる
      • 0呼 (よ) ぶ → 0呼 (よ) ばれる
      • 1飲 (の) む → 3飲 (の) まれる
      • 1帰 (かえ) る → 4帰 (かえ) られる
  • 上下段動詞
    • 變化規則：動詞去掉語尾 (る) 直接＋ら＋れる。
    • 重音規則：若原型動詞的重音為 0，則變化後重音在 0；若不是 0，則重音在 れ。
    • 範例：
      • 0借 (か) りる → 0借 (か) りられる
      • 2食 (た) べる → 4食 (た) べられる
  • 變格活用動詞
    • 1来 (く) る → 3来 (こ) られる
    • 0する → 0される

使役形

將動詞變化成另外一個動詞，所有變化後的動詞皆為上下段動詞，並且在原本的意思加上「讓...、使...」。例如：買 (か) う 的使役形為 買 (か) わせる，意思由原本的「買」變成「讓...買、使...買」。

  • 五段動詞
    • 變化規則：ない 形＋せる。
    • 重音規則：若原型動詞的重音為 0，則變化後重音在 0；若不是 0，則重音在 せ。
    • 範例：
      • 0買 (か) う → 0買 (か) わせる
      • 1書 (か) く → 3書 (か) かせる
      • 1脱 (ぬ) ぐ → 3脱 (ぬ) がせる
      • 0なくす → 0なくさせる
      • 1待 (ま) つ → 3待 (ま) たせる
      • 0死 (し) ぬ → 0死 (し) なせる
      • 0呼 (よ) ぶ → 0呼 (よ) ばせる
      • 1飲 (の) む → 3飲 (の) ませる
      • 1帰 (かえ) る → 4帰 (かえ) らせる
  • 上下段動詞
    • 變化規則：動詞去掉語尾 (る) 直接＋さ＋せる。
    • 重音規則：若原型動詞的重音為 0，則變化後重音在 0；若不是 0，則重音在 せ。
    • 範例：
      • 0借 (か) りる → 0借 (か) りさせる
      • 2食 (た) べる → 4食 (た) べさせる
  • 變格活用動詞
    • 1来 (く) る → 3来 (こ) させる
    • 0する → 0させる

尊敬形

變化規則與重音規則和受身形 (うけみ) 一樣。

  • 五段動詞
    • 變化規則：ない 形＋れる。
    • 重音規則：若原型動詞的重音為 0，則變化後重音在 0；若不是 0，則重音在 れ。
    • 範例：
      • 0買 (か) う → 0買 (か) われる
      • 1書 (か) く → 3書 (か) かれる
      • 1脱 (ぬ) ぐ → 3脱 (ぬ) がれる
      • 0なくす → 0なくされる
      • 1待 (ま) つ → 3待 (ま) たれる
      • 0死 (し) ぬ → 0死 (し) なれる
      • 0呼 (よ) ぶ → 0呼 (よ) ばれる
      • 1飲 (の) む → 3飲 (の) まれる
      • 1帰 (かえ) る → 4帰 (かえ) られる
  • 上下段動詞
    • 變化規則：動詞去掉語尾 (る) 直接＋ら＋れる。
    • 重音規則：若原型動詞的重音為 0，則變化後重音在 0；若不是 0，則重音在 れ。
    • 範例：
      • 0借 (か) りる → 0借 (か) りられる
      • 2食 (た) べる → 4食 (た) べられる
  • 變格活用動詞
    • 1来 (く) る → 3来 (こ) られる
    • 0する → 0される
      • 或直接用 する 的尊敬語 2なさる 來取代。

結語

除了理解文中詳細列出的動詞變化規則與重音規則外，還需要搭配大量的練習才能將這些規則內化到心裡，使動詞變化成為反射動作，避免在使用到的時候才從頭開始推導。因此在 [日語] 動詞變化表 一文中記錄常見的動詞與變化形式並且標上重音，使讀者方便隨時練習。
